Chart rules

  • White page, hairline containers, no shadows, no rounded corners.
  • Blue subject vs slate benchmark on every performance chart.
  • Red appears only when something is lost or failed — never decorative.
  • Composition stacks use the muted 12-tone cycle + hatching; series use the saturated cycle.
  • Drawdown is an area, equity is a line on log scale.

    • Voice

  • Every page opens with one plain-language sentence stating the verdict.
  • Evidence-first: saved artifacts, timestamps, provenance visible.
  • DEMO DATA / MOCKUP badges whenever data is not real.
  • The console is a workbench, not a landing page — no hero sections, no decoration.
