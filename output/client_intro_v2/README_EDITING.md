## איך עורכים טקסט

1. פתחו את קובץ ה־HTML בכל עורך טקסט (VS Code / Notepad++).
2. חפשו (Ctrl+F) את המשפט שרוצים לשנות — כל הטקסט העברי יושב כמו שהוא בתוך הקובץ.
3. שמרו.
4. **בדיקה מהירה:** דאבל-קליק על קובץ ה־HTML פותח אותו בדפדפן — מה שרואים שם הוא מה שיהיה ב־PDF.
5. הריצו `render_pdfs.cmd` להפקת ה־PDF המעודכן. (נדרש אינטרנט — הפונטים נטענים מ־Google Fonts.)
